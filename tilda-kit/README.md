# tilda-kit

`zg.js` собирает Zero Block из спецификации прямо в редакторе Тильды. Правила переноса и порядок работы живут в скилле `figma-to-tilda-zero`, здесь только устройство инструмента и ловушки редактора.

## Загрузка
```js
if (!window.ZG) eval(await (await fetch("https://raw.githubusercontent.com/MiZaRiii/claude-tools/main/tilda-kit/zg.js", { cache: "no-store" })).text());
```
Запасной адрес: `https://cdn.jsdelivr.net/gh/MiZaRiii/claude-tools@main/tilda-kit/zg.js` (jsDelivr кэширует `@main`, свежую версию брать с тегом или SHA).
Версия: `ZG.version`. Окно редактора `ZG` ищет заново в `ZG.ready()` (его вызывает `build`). Если зашли в другой блок в той же вкладке, перед `dump`/`patch` вызвать `await ZG.ready()`.

## Ловушки редактора и обходы (учтены в `zg.js`)
| Ловушка | Обход |
|---|---|
| Ctrl+A не берёт слои, скрытые на текущем адаптиве | `ZG.clear()` чистит на каждом адаптиве, затем на базовом |
| После очистки высота артборда = Fixed 0 | `build` снова ставит hug (Auto) |
| Редактор делает корневые группы fill → fixed | `build` возвращает fill на всех адаптивах; после ручных правок проверить |
| Свободная группа: дети в абсолютных координатах, размер = bbox всех детей, включая скрытых | `freeGroups` выставляет геометрию; скрытых держать внутри границ группы |
| Порядок в буфере: дети автокомпоновки обратные, дети свободной группы прямые, корни свободного артборда обратные | `finalize` |
| Поля `-res-<W>` для небазовых адаптивов; `img` и «Upload to Tilda» только на базовом | `zg.js` пишет суффиксы сам |
| Zero может автосохраниться без «Сохранить»; дубликат берёт сохранённую версию | поэтому новая итерация делается в дубликате |
| Предпросмотр Tilda не выполняет T123 | проверять на опубликованной странице или локальной копии разметки |

## Внутренности
- Буфер Zero: `localStorage['tn_store_buffer__copy-paste'] = {res, data:[nodes], timestamp}`, затем синтетический Ctrl+V.
- Правка существующего элемента: `elem__setFieldValue(el, field, value, 'render', 'updateui', res)`.
- Переключение адаптива: `zero.core__switchResolution(r)`.
- Кернинг: целые px (`% / 100 × округлённый размер`, округление до целого, ноль не задаётся).
